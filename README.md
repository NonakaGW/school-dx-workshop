# 学校のDX化を考える｜研修ポータル（GitHub Pages用）

このフォルダは **GitHub Pagesにそのまま公開できる静的サイト一式** です。
`index.html` をサイトのトップページとして使用します。外部ライブラリ、サーバー側のコード、ビルド処理は不要です。

## 内容

- `index.html`：トップページ・35枚のスライドビューワー・各ページへのリンク
- `slides/`：更新版PowerPointから変換したWebP画像35枚
- `downloads/研修スライド.pdf`：研修スライドのPDF版（発表者ノートなし）
- `apps/`：電子掲示板・行事実施要項作成アプリ、および共通ナビ付きの表示ページ
- `materials/texts.html`：会議メモ・前年要項・今年度変更点・JSデモコード
- `materials/prompts.html`：コピーして使える指示文
- `materials/safety.html`：利用上の注意
- `demos/auto-form.html`：JavaScript自動入力の練習用フォーム

## GitHub Pagesに公開する方法

1. GitHubに新規リポジトリを作成します。公開用データなので **Public** リポジトリを推奨します。
2. このフォルダ **の中身をすべて** リポジトリの最上位にアップロードします。フォルダごと一階層下に置かないでください。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source: Deploy from a branch** を選び、Branch: **main**、Folder: **/(root)** にして保存します。
5. GitHub Pagesが公開するURLを開き、トップ、スライドのページ送り、アプリ、テキストコピー、PDFリンクを確認します。

一般的なリポジトリの公開URL例：`https://<username>.github.io/<repository>/`
公開URLはGitHub Pagesの設定画面で確認してください。

## 公開前の確認ポイント

- GitHub Pagesは **公開サイト** です。学校の実データ、個人情報、認証情報などを追加しないでください。
- 研修のPowerPoint本体（発表者ノートを含む）は公開ファイルには入れていません。代わりにPDFと35枚の画像を掲載しています。
- 「電子掲示板を作成したチャット」は外部のChatGPT共有URLを開きます。共有の可否を確認してください。
- 2つのアプリの `localStorage` は **ブラウザ・サイトのドメインごと** に保存されます。サイトの公開形態を変えた場合、保存した内容を引き継げない可能性があります。
- JSONバックアップ等をアプリが提供している場合は必要に応じて取得してください。
- JavaScript自動入力コードはサイト内の練習用フォームだけで実行できるようにしています。実際の学校システムには貼り付けないでください。
- 生成AIが作ったコードでも安全性が自動的に保証されるわけではありません。実務導入には十分な検証が必要です。

## スライドの更新

現在のスライドはアップロードされた修正版PPTXをWebP画像に変換したものです。
スライドを更新する場合は、最新版から画像を再生成して `slides/slide-01.webp` ～ `slide-35.webp` を差し替えてください。枚数が変わる場合は `index.html` のスライド番号（maxなど）も修正が必要です。

## ローカル確認

`index.html` をChrome/Edgeで開くと基本的な動作を確認できます。ブラウザの制限により一部のファイル操作はGitHub Pages上の方が確実です。
